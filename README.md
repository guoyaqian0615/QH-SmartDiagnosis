# 本草智诊 —— 基于知识图谱的中医大模型辅助诊疗系统

> 面向大众与基层场景的中医智能辅助问诊系统，实现可解释问诊辨证、体质测评、个性化调理、健康档案闭环管理。 ⚠️ 提示：本系统仅作科普与辅助参考，**不替代执业中医师临床诊断，不能用于临床诊疗**。

## 项目介绍

### 项目背景

国内中医医疗资源供给存在缺口，基层中医服务覆盖率有限；通用大模型用于中医问诊普遍存在推理黑箱、依据缺失、辨证结论泛化，输出结果无法核验的痛点。 本草智诊融合**内存知识图谱规则约束 + 大语言模型**，打破 AI 辨证黑箱，将输出质量从 “表述看起来合理” 提升到 “推导过程可验证”。

### 核心能力

1. **体质辨识评估**：标准化中医体质问卷，输出体质倾向评分，作为问诊先验条件。
2. **知识图谱智能问诊**：接收用户自然语言主诉，内存知识图谱完成实体、权重、路径推理，双分支协同 + 语义门控机制约束大模型生成，输出**可溯源证据链可视化**。
3. **多源信息联合评估**：体质问卷 + 用户主诉多源信息互证，降低单一输入带来的判断偏差。
4. **分层调理方案**：输出膳食推荐、作息调理、成因分析、忌口提示，方案具备可执行性。
5. **中医百科知识库**：药材、证型、治法卡片，问诊结果关键词一键跳转查阅解释。
6. **健康档案管理**：问诊、评估记录归档，支持收藏重点方案，生成可分享健康报告，构建长期健康画像。

### 核心创新点

1. **双分支协同架构**：将语言生成分支、内存知识图谱结构化约束分支解耦再融合，兼顾对话自然度与事实可靠性。
2. **语义门控融合机制**：对比图谱证据与大模型输出语义一致性，执行放行 / 修正重生成，主动抑制大模型幻觉。
3. **证据链可视化**：把`症状—证型—治则—调理方案`推理路径可视化展示，实现推导过程可核验。
4. **闭环健康管理**：从单次问答升级为轻量健康管理助手，沉淀用户连续健康档案。

## 技术架构

### 技术栈

- **前端 & 后端一体**：Next.js 14（React + TypeScript）
- **业务数据库**：PostgreSQL（存储用户、问卷作答、健康档案、收藏记录）
- **ORM**：Prisma，管理数据表、数据迁移、种子数据
- **大模型服务**：DeepSeek‑V4.1‑Flash API，JSON 结构化输出
- **知识图谱**：静态 JSON 规则包，服务启动加载为**内存知识图谱**，带实体、关系、权重，用于推理与前端证据链渲染
- **百科知识库**：JSON 词条库，提供中医术语、药材、治法卡片数据
- **部署**：Docker Compose 容器编排

### 系统分层

1. 数据层
   - PostgreSQL 业务库：用户账号、体质问卷、问诊记录、健康档案、收藏
   - 静态 JSON 知识库：辨证规则图谱 + 中医百科词条（内存加载推理，无需额外图数据库）
2. **感知层**：问卷解析引擎、图谱约束生成引擎，完成问卷解析、语义抽取、知识检索
3. **推理层**：体质评估模块、知识图谱智能问诊模块、融合校验模块（语义门控、置信度融合）
4. **应用层**：体质辨识、智能问诊、中医百科、健康报告，对外提供全部业务功能

> 扩展说明：当前原型采用内存 JSON 知识图谱便于快速迭代；后续知识库规模扩大，可迁移至 Neo4j 图数据库实现大规模持久化多跳检索。

## 安装运行指南

### 环境依赖

- Node.js >= 18
- Docker & Docker Compose
- DeepSeek API‑Key（申请自 DeepSeek 开放平台）

### 1. 克隆项目

```
git clone xxx.git
cd dbcnet‑tcm
```

### 2. 配置环境变量

复制环境模板

```
cp .env.example .env
```

编辑`.env`文件，填写核心配置

```
# DeepSeek大模型配置
DEEPSEEK_API_KEY=你的api‑key
DEEPSEEK_API_BASE=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek‑v4‑flash
DEEPSEEK_TIMEOUT_MS=20000

# PostgreSQL数据库
DATABASE_URL="postgresql://postgres:postgres@localhost:5432/dbcnet?schema=public"

# 会话加密密钥，至少16位随机字符串
AUTH_SECRET=随机长字符串
NEXT_PUBLIC_API_BASE=
```

### 3. 启动 PostgreSQL 数据库

```
docker compose up -d db
```

### 4. 初始化数据库（Prisma）

```
npm install
npx prisma db:migrate
npx prisma db:seed
```

> 种子内置演示账号：`demo@example.com` / `demo1234`

### 5. 本地开发启动

```
npm run dev
```

访问：`http://localhost:3000`

### 6. 生产构建 & 启动

```
npm run build:clean
npm run start
```

### 完整容器部署

> docker-compose.yml 仅编排 PostgreSQL 与 Next 应用；知识图谱 JSON 内置项目代码，无需额外服务

```
docker compose up -d
```

## 注意事项

1. **医疗免责声明**：本项目仅作为 AI 辅助科普原型系统，输出内容仅供参考，**不能替代执业中医师诊断，不可直接作为用药、诊疗依据，身体不适请及时线下就医**。
2. 原型版本知识图谱为内存 JSON 实现，知识库规模有限，复杂兼夹证场景置信度存在优化空间。
3. 用户问诊、体质属于敏感健康信息，生产部署务必开启数据脱敏，禁止明文日志输出隐私内容。
4. 后续迭代方向：扩充中医实体规则、迁移专业图数据库、小规模场景试点试用。
